RAMS’ Bank is a console banking program written in C++. User details (name, account number, PIN and balance) are stored in four parallel arrays, where the same index belongs to the same person. When the program starts, the user has 3 attempts to log in with their account number and PIN. The login function searches the arrays for a matching account number and PIN and returns that user’s index. After logging in, a menu is displayed inside a do...while loop and a switch statement runs the option the user picks: deposit adds money to their balance, withdraw subtracts money (and rejects amounts larger than the balance), send cash moves money to another account found by its account number, and check balance displays the current balance. The menu repeats until the user selects Exit.
